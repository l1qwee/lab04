1. Что показывает Environment.ProcessorCount? колво доступных логических процессов
2. Чем физическое ядро отличается от логического процессора? тем что в 1 физическом ядре может быть несколько логических процессов, а базово логические процессы это виртуальная ед обработки данных, а физ ядро это реальный и независимый аппаратный блок внутри процессора
3. Почему увеличение количества потоков может увеличить загрузкуCPU? из-за Параллельного выполнения и из-за заполнения "пауз"
4. Почему после некоторого количества потоков загрузка не обязательно продолжает расти? из-за пределов масштабирования
5. Почему частота процессора может изменяться во время работы? из-за:
1. Энергосбережение
2. Троттлинга
3. Технология авторазгона
4. Характера инструкций

Environment.ProcessorCount== 8
Почему это не противоречие? потому что кол-во физ ядер != кол-ву логических процессов
